# Sistema de Empleados

Sistema de gestión de empleados desarrollado en Python que permite registrar,
consultar, editar y eliminar empleados mediante una aplicación de consola.
Los datos se almacenan localmente utilizando una base de datos SQLite.

## Funcionalidades
- Registrar empleados
- Buscar empleados
- Editar empleados
- Eliminar empleados
- Persistencia de datos con SQLite

## Tecnologías
- Python
- SQLite
- SQL
- Git
- GitHub

## Ejecución
```bash
python main.py
```
